# RallyRivals master palette (ADR-003)

ONE palette shared by voxel models, terrain, FX and UI accents — coherence comes from colour
discipline, not from voxelizing the world. 19 ramps x 6 shades = 114 colours, darkest -> lightest.
Original palette (no external licence); generated by `scripts/tools/gen_palette.gd` — edit the
ramp endpoints there and regenerate, the PNGs are artifacts.

| file | purpose |
|------|---------|
| `rallyrivals_palette.png` | 256x1 strip — load in MagicaVoxel: Palette panel -> open -> this file |
| `rallyrivals_swatches.png` | human-readable sheet, one ramp per row |

## Brand triads

The three colours `scripts/tools/gen_voxel_cars.gd` reads per brand. `shade` is the SEAM CONTRAST,
not simply "darker" — direction follows the body's own value, so it flips between brands.

| brand | body | seam | accent |
|-------|------|------|--------|
| Apex Cartel | 90 `#e7e4da` L 0.78 | 99 `#c4c1b5` (darker) | 74 `#c9303e` red |
| Wreckhouse | 104 `#0d2b52` L 0.02 | 107 `#5b8fc9` (**lighter** — a navy body swallows a dark seam) | 91 `#ff8c00` orange |
| Mayfly Speedworks | 112 `#e0b81f` L 0.50 | 110 `#8a5a12` (darker, and orange-SHIFTED) | 86 `#202d85` indigo |

The three body values are deliberately spread 0.78 / 0.50 / 0.02 so a brand is legible at race
distance before any detail resolves. Mayfly was pale cyan `#abf5ed` until it measured at L 0.80 —
*lighter than Apex* — and both brands read as the same white car.

Each brand's wheel hub is its accent (`gen_voxel_wheels.gd`): Apex red, Wreckhouse orange,
Mayfly indigo.

**Known trap:** the amber indicator `#ff8c00` against the Mayfly gold body is contrast 1.23 at 15
degrees of hue — invisible in both value and hue. Mayfly lamp recesses need a seam-colour outline
so the lens reads as an object. The other two brands are fine (Apex 1.83, Wreckhouse 6.06).

## Rules

- **Pinned cells never move** — they are the `SurfaceType.color` classifier anchors; painted
  track images depend on them. Re-tint anything else freely, regenerate, re-export models.
- **Never reorder existing slots** once voxel models exist — their UVs index the strip.
  New ramps append at the end only. Re-tinting a ramp in place is safe *only* while no baked
  model reads it (which is how Mayfly went cyan -> gold: no Mayfly car existed yet).
- Shade INSIDE a ramp (step along the row), don't cross-mix ramps for shading.
- **Sub-slot differences do not exist.** Two colours a hand-painter cannot tell apart in the
  MagicaVoxel palette are one colour — slot 92 and slot 112 were byte-identical for a while and
  the "accent" silently painted body.
- Terrain/splat colours and MagicaVoxel palettes both come from here — if a colour isn't on
  the board, it isn't in the game.
